# Hello Skill

A minimal template. Copy this folder, rename it, and update the frontmatter.

## Instructions

1. Explain that every skill lives in `skills/<skill-name>/SKILL.md`.
2. The folder name must equal the `name` field.
3. Put longer material in `references/` and helper code in `scripts/`.
