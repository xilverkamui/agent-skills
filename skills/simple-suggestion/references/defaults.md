# Defaults

Edit this file once for your team. The skill reads it before asking header questions, so anything listed here is not asked again.

| Setting | Value |
|---|---|
| Departemen | TNT |
| Date format | `<day> <Indonesian month> <year>`, e.g. `9 November 2026` |
| Date default | today |

Approvers are not stored here. They differ per team, so the skill always asks the user for them as part of the header data:

- Supervisor/Manager (2), shown under "Diperiksa oleh".
- Manager/ Dept Head (3), shown under "Disetujui".

Dept. Cont. Improvement (4) and No. Reg are filled by the CI department; leave them blank unless the user gives them.
